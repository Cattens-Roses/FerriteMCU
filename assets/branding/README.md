# ferriteMCU logo pack

Original, editable SVG logo assets for ferriteMCU, an IDE concept for embedded Rust development, including ESP32 boards.

## Files

- `ferriteMCU-mark.svg`: standalone transparent symbol for an app icon, IDE sidebar, splash screen, or favicon.
- `ferriteMCU-wordmark.svg`: wordmark for light surfaces.
- `ferriteMCU-wordmark-dark.svg`: wordmark for dark surfaces.
- `ferriteMCU-preview.html`: local preview of the variants.

## Design

The open circular core refers to ferrite. The copper-colored terminals and traces refer to windings and embedded hardware. The central F is the first letter of ferrite. The warm accent is an original palette choice for Rust-oriented tooling and does not use the Rust logo.

## Palette

- Graphite: `#26333D`
- Copper: `#E47745`
- Paper: `#F2F4F2`
- Muted steel: `#64717B`

The SVGs have transparent backgrounds. The wordmark uses a system font stack (`Inter`, `Segoe UI`, `Arial`, sans-serif) so no font files are needed. Text remains editable in SVG-aware design tools.

## Use

Use the mark alone in compact IDE surfaces. Use the light wordmark on a light background and the dark variant on a dark background. All supplied artwork is original vector work and can be modified for the project.
